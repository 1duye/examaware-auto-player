# 自动放映

ClassIsland 那边把考试排好，ExamAware 这边到点自己开播，考完自己退。

---

## 为什么有这个东西

考场里最常见的操作是：老师在 ClassIsland 里看着课表，考试铃一响，切到 ExamAware、找到当天的考试档案、双击、全屏，考完再退出来。一天两场就是四遍，遇上连堂还得盯着时间。

这个插件把后半段接过去了：只要 ClassIsland 端把「哪天、第几节、考什么」推过来，它就在开考前自己打开档案、全屏、置顶，结束后按设定延迟退出。中间不用人管。

配合 ClassIsland 插件 **「ExamAware2联系人」**（`classisland.exam-recorder`）一起用，由它负责生成当天的 `.ea2` 档案并把路径推过来。

## 它能做什么

- **考前自动放映**：可设提前 0–60 分钟进入放映，全屏 + 置顶。
- **考后自动退出**：可设结束后延迟 0–300 秒退出，不会收卷那一秒就把画面切走。
- **按时间挑场次**：一天多场会自己接续；放映中收到新信号不会打断当前场次。
- **中途恢复**：ClassIsland 或 ExamAware 中途重启，正在进行的场次会被重新接上。
- **总开关**：临时不想自动播就关掉，信号照收，不会自己开播。
- **立即停止**：误触发了点一下就能结束。
- **状态看得见**：设置页显示连接状态、距下一场还有多久、当前场次、最近一次信号和错误。

## 安装

1. 确认 ExamAware 桌面端已开启 **设置 → HTTP API**。
2. 在 **设置 → 插件 → 安装** 里选 `examaware-auto-player-<版本>.ea2x`；也可以解压到插件目录后重启 ExamAware。
3. 装好后在「插件」页把它启用，设置里会多出一个 **自动放映** 页。

## 用起来

1. 在 ClassIsland 里把要考的科目标成「考试科目」（档案编辑 → 科目 → 更多选项 → 考试科目）。
2. 把这些科目排进当天课表。
3. 考试当天什么都不用做。插件会读 ClassIsland 推来的档案，挑出正在进行或最近的场次，到点开播。

> 只有被标成「考试科目」的课才会触发，普通课不受影响。

## 设置

**设置 → 自动放映**：

| 设置项 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 自动放映 | 开 / 关 | 开 | 总开关。关掉后仍收信号，但不会自动开播。 |
| 提前启动 | 0–60 分钟 | 5 | 开考前多久进入放映。 |
| 延迟退出 | 0–300 秒 | 30 | 考完后延迟多久退出。 |
| 端口自动上报 | 开 / 关 | 开 | 把当前 HTTP API 端口写到发现文件，ClassIsland 端自动跟随（见下）。 |

设置页还会显示连接状态、倒计时、当前场次、最近一次信号，并提供「连通性自检」和「立即停止放映」。

## 关于端口

ExamAware 的 HTTP API 端口并不总是固定的：它在启动时会重启自己的 HTTP 服务，旧监听器还没释放就重新绑定，端口被占用就顺延到下一个，并把顺延结果写回配置。于是一路重启、一路往后挪。

这带来的真实问题不是"端口变了"，而是**ClassIsland 端记着一个过期端口，推送直接被拒绝**。以前的报错长这样：

```
push -> http://127.0.0.1:31325/api/v1/examaware-auto-player/signal
push fail: 由于目标计算机积极拒绝，无法连接。 (127.0.0.1:31325)
```

现在的做法是**上报 + 跟随**，不跟宿主抢端口：

- 本插件每 5 秒把当前地址写到 `%APPDATA%\@dsz-examaware\desktop\auto-player-endpoint.json`；
- ClassIsland 端推送前读这个文件，用里面的端口，端口怎么飘都能跟上。

所以两边的端口**不需要手工对齐**。设置页里那行「EA 当前端口」只是给你看宿主现在报的是哪个端口。

> 早期版本试过用宿主的 `http.configure` 把端口硬钉住，结果和宿主自己的重启互相打架，反而让 EA 设置页报「端口被占用」。

## 已知问题

- **必须开 ExamAware 的 HTTP API**。没开时设置页会显示「服务离线」，信号也收不到。
- **只在本机通信**。插件只监听 127.0.0.1，不支持跨电脑。
- **宿主侧的老毛病**：插件贡献的设置页如果包名带作用域（`@scope/name`），id 里会多一个 `/`，宿主路由匹配不上，设置页会整块空白。本插件因此不带作用域前缀（叫 `examaware-auto-player`），不是随手起的名字。
- **宿主可能把端口顺延到别的数字**，EA 设置页显示的数字和插件设置页显示的「EA 当前端口」可能不一致；以插件上报的为准。
- **考完的场次不会补播**。ClassIsland 在考试开始后才启动的话，进行中的场次能不能恢复取决于 ClassIsland 端推的档案。
- **依赖档案内容合法**。档案坏了、`examInfos` 是空的、时间格式不对，这次信号会被拒（设置页「最近一次错误」会写原因）。

## 常见问题

**设置页显示「服务离线」？**
先确认 ExamAware 开了 HTTP API；再点一下「连通性自检」看具体报错。如果刚改过设置，等一两秒。

**到点了没自动播？**
依次看：ClassIsland 那边有没有推成功、插件「最近一次信号」有没有记录、那场考试是不是已经结束了（只排未结束和未来的场次）。

**想提前结束？**
设置页点「立即停止放映」。

**误把普通课标成考试了？**
去 ClassIsland 的科目「更多选项」里关掉「考试科目」
